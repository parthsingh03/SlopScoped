Paste a GitHub username. SlopScoped reads the public record — file trees, commit history, READMEs, sampled code — and estimates how much of the profile is AI-made. Every point in the score is tied to evidence you can click and check yourself. No evidence, no accusation.

The URL swap

Take any GitHub profile and swap the domain:

github.com/Ayush442842q  →  parthsingh03.github.io/SlopScoped/Ayush442842q

Public profiles only. Forks are excluded from the score — a fork is someone else's work. At most the 12 largest non-fork repos are deep-scanned.

Honest limits

This is an estimator, not a lie detector. It catches what the public record shows: automation pipelines, batch-generation commit patterns, template code. A low score means no strong public evidence — not "proven human". Careful AI-assisted work, iterated locally and pushed finished, leaves few traces, and this tool will not invent traces that aren't there. Read how the scoring works.
