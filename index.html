Public profiles and repos only. In profile mode, forks are excluded from the score — a fork is someone else's work. At most the 12 largest non-fork repos are deep-scanned.

How the scoring works

Every repo is scored 0–100 purely from evidence in its public record. No evidence, no points. This is the whole chart — nothing is hidden.

ScoreVerdictWhat it means
proofProven AI-automatedAn automation script in the repo tells an AI agent to generate code and push it. Case closed.
80–100Highly likely AI-automatedMultiple strong signals stack up — dumps, batch commits, templates.
50–79Likely AI-generatedClear AI-generation patterns, short of a smoking gun.
25–49AI-assistedSome AI tooling traces — agent folders, a few template signals.
0–24No strong AI evidenceThe public record shows little to nothing. Not "proven human".

🔫 Hard evidence

  • Automation script (AI generates + git-pushes) → proven, floor 95
  • .claude/ or .agents/ folder committed → +35
  • Prompt files committed → +20
  • CLAUDE.md / .cursorrules → +15

📦 Commit behaviour (max +35)

  • Whole repo landed in ≤2 commits → +10
  • One message repeated for >50% of commits → up to +15
  • "Add 5 new tools" batch messages ≥20% → +15
  • All commits squeezed into ≤3 days, 30+ files → +10
  • Almost zero fix/debug commits → +5

🧬 Code & README (max +30)

  • Identical template opening across sampled files → +10
  • Heavy generic-comment padding → +10
  • README with 4+ AI tells (buzzwords, emoji headers) → +10
  • 100+ code files in one flat pile → +10

🧑 Human signals (subtract)

  • Fix/debug commits in a plausible 15–60% band → −10
  • History spanning 90+ days with varied messages → −10

Profile score = repo scores weighted by repo size, shown as a ±10 range. Forks never count.

Full rules with exact thresholds: SCORING.md.

Honest limits

This is an estimator, not a lie detector. It catches what the public record shows: automation pipelines, batch-generation commit patterns, template code. A low score means no strong public evidence — not "proven human". Careful AI-assisted work, iterated locally and pushed finished, leaves few traces, and this tool will not invent traces that aren't there. Read how the scoring works.
